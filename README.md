# Дровосек-спасатель 🌲

Игра курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

## Об игре

Ты — дровосек. Рубишь ствол влево/вправо и уворачиваешься от веток, чтобы снять с них **30 лесников**.

Лесник сидит прямо на ветке и кричит SOS. Ветки с лесниками попадаются случайно — примерно через 5–12 рубок. Руби ствол, пока его ветка спускается вниз, и в последний момент стой с другой стороны от ветки — тогда лесник спасён. Встанешь под ветку — удар: **−1 жизнь** (всего 3) и оглушение (короткое время рубить нельзя), а лесник с этой ветки падает. Долго стоишь без дела — появляется шкала «⏳ РУБИ!»: если дотянуть до пустой шкалы, тоже сгорает жизнь.

**Победа:** спасти всех 30 лесников.
**Поражение:** потерять все 3 жизни.
**Счёт:** время — чем быстрее спас всех, тем лучше. Лучшее время сохраняется как рекорд 🏆.

### Управление

Перед игрой выбирается режим (кнопкой или клавишей **1 / 2**):

| Режим | Как рубить |
| --- | --- |
| 🔤 Буквы | жми букву с нижнего бревна; верная — безопасная рубка, неверная — удар |
| 🪓 Классика | **←** / **A** слева, **→** / **D** справа, либо клик по половине экрана |

Начать заново — **R** или клик на финальном экране. Счёт (время) идёт с первой удачной рубки.

## 1. Что нужно установить

- **Node.js 22 LTS** (или Node.js >= 20.19)
- **Git**
- **VS Code** или другая IDE
- аккаунт **GitHub**

Проверка:

```bash
node --version
npm --version
git --version
```

## 2. Первый запуск

```bash
npm install
npm run dev
```

Vite напечатает адрес локального сервера. Обычно это:

```text
http://localhost:5173/
```

Открой его в браузере.

## 3. Что менять в первую очередь

Главный файл для первой практики:

```text
src/game/GameScene.ts
```

Начинай с маленьких изменений:

1. измени поведение игрока;
2. добавь одно игровое действие;
3. добавь реакцию игры;
4. добавь цель или результат;
5. добавь препятствие / риск / условие поражения;
6. добавь Restart.

**Не начинай с меню, магазина, красивой графики и архитектуры на 30 файлов.**

## 4. Проверка production build

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 5. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.

